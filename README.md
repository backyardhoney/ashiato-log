# あしあと絵図

某メーカーのスマートウォッチやサイクルコンピューターに溜まった足あとを、地図の上にまとめて眺めるためのツールです。

**▶ 使ってみる: https://backyardhoney.github.io/ashiato-log/**

本気のデータ解析はできません。
「この道、何回走ったんだっけ」「意外とこんなとこまで行ってたな」と、ニヤニヤするための道具です。

## できること

- ランニングは橙色、バイクは青色、ウォーキングは薄い黄色で、全部の経路を1枚の地図に重ねます。
- 同じ道は1本にまとめます。毎日同じコースを走る人の地図は、地味なままです。
- 拡大すると、ランはシューズの跡、ウォーキングは素足の足跡、バイクはタイヤ跡になります。足跡は、スタートからゴールの向きに並びます。
- 線や足跡にカーソルを当てる(スマホはタップ)と、その1本が強調されて、アクティビティ名・距離・時間・心拍などが出ます。
- 期間(今年、直近1年など)で絞り込めます。
- 自宅の周りは、お好みで隠せます。出発とゴールの近くを、毎回少し形を変えながら消します。

## 使い方

1. 使っているウォッチのアカウントの「データ管理」から、全データのエクスポートを依頼する。
2. 届いたメールのリンクから、zipをダウンロードする(解凍は不要です)。
3. ページを開いて、zipを画面にドロップする(スマホは「ファイルを選ぶ」)。

FIT形式のファイルであれば、ほかのサービスや機器のデータでも使えるかもしれません。
(動作確認は一部のデータだけなので、うまく表示できないこともあります)

## 人に見せるときの注意

自宅の隠し方は完全ではありません。

- 隠すのは、出発とゴールの付近だけです。近くを通っただけの道は表示されます。
- 隠した範囲の外側に道が集まっていると、家のあるあたりは推測できます。
- 画面のスクリーンショットを何枚も見せると、隠した形の違いから位置が絞られやすくなります。

家を知られたくない相手に見せるときは、半径を大きめにするか、自宅近くの経路を除いてから見せてください。

## データの扱い

- 走行データは、お使いの端末(パソコンやスマホ)の中だけで処理します。作者のサーバーへは送りません(そもそもサーバーを持っていません)。
- Web版のページには、訪問数だけを数えるアクセス集計(GoatCounter、cookieなし)を入れています。走行データや位置情報は含まれません。(exe版・HTML単体版には入っていません)
- 背景地図の画像は、国土地理院から取得します。表示している範囲の地図が、配信元に伝わります。
